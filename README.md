# Torneo de Mesa

Aplicación web progresiva (PWA) para organizar el torneo de juegos de mesa de mi grupo de amigos: jugadores, partidas, puntajes, tabla de posiciones y anfitrión de cada fecha.

- **PWA instalable** en el celular, con service worker para uso sin conexión
- **Firebase** (autenticación con Google y Realtime Database) con reglas de seguridad por correo verificado y roles de administrador
- **Pruebas automáticas** de las reglas de la base de datos (`npm test`)
- JavaScript modular sin frameworks: puntajes, tabla, sincronización y textos en módulos separados

---

*Progressive web app to run my friends' board game tournament: players, matches, scoring, standings and hosts. Installable PWA with offline support, Firebase auth and Realtime Database with tested security rules, vanilla modular JavaScript.*
